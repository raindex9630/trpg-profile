# シナリオ・HO管理アプリ

TRPGの通過済みシナリオと予定を管理するためのデスクトップアプリケーションです。
ローカルのJSONファイルを読み込み、GUIで直感的に編集・保存が可能です。

## 必要要件
* Python 3.11 以上
* Tkinter (Python標準ライブラリ)

## 起動方法

以下のコマンドで起動します。

```bash
python app.py
```

起動後、メニューの「ファイル」→「開く」から管理用のJSONファイルを選択してください。

## 使い方

### Passed (通過済み) タブ
* **グループ操作**: 左側のリストでグループの追加、名称変更、削除、並び替えができます。
* **アイテム操作**: シナリオ（アイテム）の追加、編集、削除、移動が可能です。
* **お気に入り**: ★マークで表示されます。

### Planned (予定) タブ
* **Note**: 上部のテキストエリアでメモを自由に記述できます。
* **スケジュール**: 月ごとに予定をグループ化して管理できます。

### データ保存
* 編集内容は「ファイル」→「保存」で上書き保存されます。
* JSON形式で保存され、既存の未知のキーは保持されます。

## exe化手順 (PyInstaller)

PyInstallerを使用して単体実行ファイル(exe)を作成する場合の手順です。

1. PyInstallerをインストール（未導入の場合）
   ```bash
   pip install pyinstaller
   ```

2. 以下のコマンドを実行
   ```bash
   pyinstaller --onefile --windowed app.py
   ```

3. `dist` フォルダ内に `app.exe` が生成されます。
